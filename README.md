# Bands for Days

A free HSC study site (Business Studies first, nine more subjects): flashcards, learn/test/match modes, spaced reviews, a ratio drill, and past papers marked against the official criteria. Live at https://bandsfordays.com/ (formerly "Band Six").

- `index.html` landing page
- `app.html` the study app (everything is in one file; progress is saved in the browser)
- `papers/` the exam papers, marking guidelines, exemplars and case studies as PDFs

Hosted on Cloudflare Workers (auto-deploys from `main`); see OPERATIONS.md. GitHub Pages still serves a copy.
