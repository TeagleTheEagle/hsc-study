# Band Six

A static study site for HSC Business Studies: flashcards, learn/test/match modes, a ratio drill, and past papers (NESA HSC 2015 to 2025 plus Riverview Task 1) marked against the official criteria.

- `index.html` landing page
- `app.html` the study app (everything is in one file; progress is saved in the browser)
- `papers/` the exam papers, marking guidelines, exemplars and case studies as PDFs

Hosted with GitHub Pages from the `main` branch.
